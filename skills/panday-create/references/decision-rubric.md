# Create decision rubric

Use this rubric after reading the package workflow.

1. **Identity:** bind findings and outputs to the exact input files/revision.
2. **Purpose:** assess only the capability requested: Derive a reusable skill from a demonstrated unmet task and produce a package with trigger, procedure, boundaries, and evals.
3. **Evidence:** separate directly observed facts from inference and unknowns.
4. **Authority:** keep review, recommendation, and write permission distinct. Preview before external effects; obtain authorization for the concrete destination and operation.
5. **Disposition:** report outcome, limitations, unresolved items, and the next safe step. Never turn missing evidence into a positive claim.
