# Panday icon refinement plan

Research: Lucide's design principles recommend consistent strokes, round joins, safe padding, visual centering and low detail density. Fluent recommends reducing detail for small icons. Sources: https://lucide.dev/contribute/icons/design-principles and https://fluent2.microsoft.design/iconography/.

Plan: preserve the navy rounded tiles; remove competing corner marks; use a consistent 3.5-unit stroke and one accent hue; keep symbols within the live area; replace ambiguous shapes with recognizable metaphors. Discover uses a magnifier, Create a new document, Inspect a shield and lens, Evaluate a chart, Fix a wrench, Install a download tray, Card an identity card, Augment an extension, Synthesize merging paths, Optimize a gauge, Connect two connected modules, Migrate a transfer between boundaries.

Review at 24px, 32px and 128px. Check clipping, shape collisions and pairwise confusion. XML checks establish valid assets, not aesthetic quality. Record only actual rendered reviews; the earlier fifteen-pass list was a checklist, not fifteen separate design iterations.
