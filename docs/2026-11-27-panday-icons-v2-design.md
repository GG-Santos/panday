# Panday icons v2 design

Purpose: make the twelve skills identifiable as one family and individually recognizable at 32px, while retaining accessible SVGs.

Visual system: 64×64 SVG; rounded-square navy tile; 40×40 live area; 3–4px main strokes; one accent color per skill; a small shared corner spark. Glyphs use a light foreground and restrained accent detail. No embedded text, gradients, filters, or external resources.

Mapping: Discover = compass/search; Create = document with add mark; Inspect = shield with magnifier; Evaluate = rubric/check bars; Fix = split seam and repair stitch; Install = package with down arrow; Card = evidence ID card; Augment = growing branch; Synthesize = two inputs into one output; Optimize = route choosing a shorter path; Connect = handshake-like two ports and bridge; Migrate = package moving across a boundary. At 32px, the primary silhouette must remain distinct without depending on hue.

Acceptance: valid XML, accessible name, no overflow, all twelve rendered together at 32px and 128px; review pairwise confusion and optical weight. Publish source on main and a new release version only after the visual review. Existing v1.0.0 remains immutable.

Research basis: [Material icon grid and optical corrections](https://m2.material.io/design/iconography/system-icons.html), [Fluent scaling and modifiers](https://fluent2.microsoft.design/iconography/), and [Carbon sizing and alignment](https://www.carbondesignsystem.com/building-blocks/foundations/icons/guidelines).
